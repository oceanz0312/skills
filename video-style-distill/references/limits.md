# 能力边界（必须事先告诉用户）

| 参考片类型 | 能蒸馏 | 不能复刻 |
|---|---|---|
| 拼贴、贴纸、定格、动态排版、图形动画、扁平插画、卡点剪辑、MG 包装 | 全部：节奏、构图、转场、字体、配色、习惯 | — |
| 实拍运镜（手持、推轨、无人机）、真人表演 | 剪辑节奏（切点网格、镜头时长分布）、包装（字幕、贴纸、转场、调色倾向、片头片尾） | 镜头运动本身、景深、实拍光影 |
| 复杂 3D、粒子、流体、VFX | 节奏、配色、版式、2D 包装层 | 3D 渲染、物理模拟 |
| AI 生成视频（Sora/可灵等） | 剪辑节奏 + 包装 | 生成画面本身（可写成"需要外部生成素材"的槽位） |

- 渲染器是 HTML Canvas 2D：能做的是图层合成、遮罩、抠图贴纸、程序化图形/纹理、逐帧定格、2D 变换。
- 字体：原片字体识别不了就用 OFL 替代，写进不确定点。音乐：不复刻原曲，用用户 BGM 重算 T。
- 判断不了时先跑测量，把"能蒸馏 / 只能蒸馏节奏和包装"的结论和理由先发给用户，再动手写 skill。
