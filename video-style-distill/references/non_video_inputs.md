# 非视频输入：图片 / 设计稿 / 品牌手册 / 设计语言描述

没有时间轴，就没有【实测】节奏。做法：**视觉语言实测 + 动效默认值推导 + 用户确认**。

1. 收集：PNG/JPG 直接用；PDF（品牌手册）`image_style.py --pdf`（pdftoppm 72dpi 转页）；Figma/Sketch/AI/PSD 让用户导出 PNG 或 PDF（本 skill 不解析原生设计文件）；文字描述原样附进草稿。
2. 实测（`image_style.py`）：画幅、色板（平涂区优先）、平涂占比、边缘密度、颗粒、饱和度、留白率、对比度、视觉重心。品牌手册里写明的色值/字体/间距**以手册为准**，覆盖测量值。
3. 推导动效默认值【推】（全部写成可调默认，不进硬锁）：
   | 测量 | 推导 |
   |---|---|
   | 画面越满/越硬朗（边缘密度高、饱和高、留白少） | T 越短：0.33 s；中等 0.42 s；留白多、柔和 0.55 s |
   | 有颗粒/纸纹或大面积平涂（手作、印刷感） | 定格 boil（2–3 态，抖动 4–14 px@1080w），不用缓动 |
   | 干净矢量/UI/扁平 | 平滑缓动（ease-out 200–400 ms），不 boil |
   | 对比强 | 硬切 + 分拍推移；对比弱 → 遮罩擦除/色块推入 |
   | 留白多 | 一屏一句；留白少 → 2–3 行信息 |
   场景长度默认 8T（≈2 小节）；有 BGM 后 T 取 BGM 的八分或四分音符，落在上表范围内。
4. 动起来的方式要从**静态构件**推：哪些是底（会 boil 的纸/色块）、哪些是主体（贴纸式入场/A/B）、哪些是信息（不动、最后出现）。
5. 先出 1 条 10–15 s 的动效样片给用户确认节奏，确认后再把 T、运动方式升为硬锁。没确认前 SKILL.md 里标"【推】待确认"。
