# 拼贴手账定格风 · 请柬视频模板

这个 skill 是对一条 38.43 秒婚礼请柬参考片（720×998，30fps）的逐帧拆解，可以复用来做新片。**节奏是模板，画面是填空**：整片挂在 T = 12.25 帧（0.408s）的定格时钟上。之所以能"像原作者做的"，靠的就是这个时钟加上一组固定的创作习惯；位置和配色都可以在范围内调整。

标签：【硬锁定】不改；【可调】在给定范围内调；【签名】原作者的习惯，必须保留；【实测】从原片量出来的；【估】目测或推断。

## 工作流程
1. **校验素材**：把用户素材整理成 `manifest.json`（照 `assets/manifest.example.json`），运行
   `python scripts/validate_manifest.py manifest.json`。有 REJECT 就先解决，问用户的顺序见下文"缺素材时问什么"；WARN 写进交付说明。
2. **定时钟**：脚本会报告 BGM 的 BPM 和建议 T。T 与 12.25 相差 ≤0.4 帧时，直接用原网格，只平移 BGM 让第一个强拍对齐；差得更多就按 timeline.md 的公式整体伸缩。原因：这套片子的辨识度来自网格本身，不是来自某首歌。
3. **抠图**：`python scripts/cutout.py in.jpg cut/S5_A.png --width 1080`（rembg 抠图 + 白边 + 1.5px 暗边）。A/B 两张要用同一个参数，白边粗细才会一致。
4. **搭场景**：按 slots.md 的默认 bbox 放，在【可调】范围内微调；层级顺序不能动（见下）。每个场景先出一张静帧，和 `assets/slot_layout.jpg` 对照着看。
5. **渲染**：把 `render(ctx, f)` 写成"帧号的纯函数"（规范见下），用 Playwright 逐帧截图，再用 ffmpeg 合成。
6. **QA**：`python scripts/qa_compare.py out.mp4 --ref ref.mp4 --T <T>`。三项检查要全部通过，再看对比拼图。参考片自己跑出来是 step 12.22 帧、残差 0.46 帧、静止帧差 0.049，可以当基准。
7. **交付**：mp4 + 对比拼图 + QA 的 JSON + 用过的 fallback 和 WARN 清单。

- **boil**：事件帧 = `round(1.48 + 12.25k)`，3 态循环；两次事件之间画面完全静止。定格感就是这样来的，一旦插值就会变成普通的 MG 动画。
- **A/B**：只在 S5–S7 出现，每 1T 硬切一次，A B A B A B。只在情绪高峰闪，闪才有力量；全片都闪会显得廉价。
- **摇镜**：每步 1T 硬切；纵向每步 0.18–0.22H，横向 0.24W。像手推长卷，不要缓动。
- **文字 boil**：原片是 11 帧一次【实测】，可以统一成 T【可调】。

## 画面规则
- **层级**【硬锁定】，从下到上：纸纹底色 → 1 个大几何色块 → 风景照片、报纸条 → 英文草书 → 白边人物 → 道具。草书放在人物下面，是为了让人物压住字的一角，这是原作的签名。
- **人物**【硬锁定】：在下半屏（底边 ≥0.93H，顶边 ≥0.27H）；同一场景脚底线对齐（误差 ≤1%H）；A/B 用同一组槽位。脚底一跳，"闪"就会读成"错帧"。
- **只有一个主变化**【硬锁定】：同一时刻要么 A/B 在闪，要么摇镜在走（boil 不算）。观众视线只追得上一样东西，这就是"灵动但不乱"。
- **位置**【可调】：槽位中心 ±10% W/H，缩放 0.8–1.2 倍，道具 0–3 件，道具静态旋转 ±15°。
- **贴纸**【实测】：白边 = 0.97% 画面宽（1080 宽时 10px）；只加 1.5px rgba(0,0,0,.25) 暗边，不加大投影，因为原作像手账贴纸，不像 PS 合成。
- **boil 幅度**【实测】：人物每态 ±5–17px@720、±1.5°；风景照片和道具 4–14px；色块和撕纸位置不动，只换纸纹；文字和标签不动。
- **背景**【签名】：真实风景或建筑照片 + 撕纸、报纸条、墙纹、色块，风景场景 4–6 片，信息场景 2–3 片；每场景只有 1 张主照片、1 个色块。拼法和随机参数见 `references/background_collage.md`。
- **色板**【实测】【可调，首尾同色必须保留】：
  - S1 砖红 #C45A4D / 橄榄 #A4A275 / 奶油 #F0DCD2
  - S2、S3、S6 芥末黄 #F4D877 + 薄荷绿 #5DAD7E（S3 加牛皮纸 #DCC8AE）
  - S4 砖红天 + 橙日
  - S5 芥末黄 + 湖蓝 #B7D5C7
  - S7 锈红 #A95842 + 奶油圆
  - S8 薰衣草灰 #D7D6E6 + 雾蓝 #6C809E
  - S9 薄荷绿 #60AB7E + 芥末黄 + 糖果粉 #EEA4BA
  - S10 砖红 #C3554B + 橄榄 #A4A581 + 粉 #EEA8BF
  - 墨色 #3A282B
- **字体**【估】【可调】：
  - 勒索信标题：Abril Fatface / Alfa Slab One / Bebas Neue 混排，每个字母配一个彩色块，旋转 ±5–12°。
  - 英文草书：Caveat Brush / Permanent Marker，字高约 0.08W，每场景换一种颜色，整行直接出现（原作不逐笔写）。
  - 中文：站酷快乐体 / 霞鹜文楷，1080 宽时 ≥36px。

## 签名速查（完整 18 条和反模式见 references/signature.md）
3 态 boil｜A/B 只在 S5–S7｜步进摇镜不缓动｜只有一次硬切，放在情话转信息处｜首尾砖红｜一场景一色块一照片一句话｜英文情话用古典文学、名人情书｜勒索信标题只出现一次｜复古实物道具｜涂鸦 ≤6 处｜冷暖交替｜字被人压住｜结尾 dress code 色卡｜TV 开场。
最容易破坏原作感的做法：任何平滑缓动或叠化、大投影或发光、满屏涂鸦、插画道具、中文写情话、草书逐笔写出。

## 渲染实现
```js
const T = 12.25;                                   // 或用 BGM 推出来的 T'
const q = f => Math.floor((f - 1.48) / T);         // 第几个时钟格
function render(ctx, f) {                          // 只依赖 f；同一个 f 渲染结果必须逐像素一致
  const s = SCENES.find(x => f >= x.start && f <= x.end);   // 来自 timeline.md 的 JSON
  const boil = ((q(f) % 3) + 3) % 3;
  const pose = s.ab ? s.ab.filter(a => a <= f).length % 2 : 0;   // 0=A，1=B；落位后到第一个 ab 帧之前是 A
  const rnd = seeded(`${s.id}|${boil}`);           // mulberry32；同一态永远同一组随机数
  drawPaper(ctx, s, boil); drawBlock(ctx, s); drawPhotos(ctx, s, rnd);
  drawScript(ctx, s); drawPeople(ctx, s, pose, rnd); drawProps(ctx, s, rnd);
  applyEnter(ctx, s, f);                           // 摇镜：n = s.enter.steps 里 ≤f 的个数，offset = (3-n)·stepFrac·尺寸
}
```
- 逐帧：Playwright 执行 `page.evaluate(i => render(ctx, i), i)`，截图存 `frames/%05d.png`。
- 合成：`ffmpeg -framerate 30 -i frames/%05d.png -i bgm.mp3 -af "afade=t=out:st=37.4:d=1" -c:v libx264 -pix_fmt yuv420p -crf 18 -t 38.43 out.mp4`。
- 输出 1080×1920：bbox 用比例，人物按底边对齐摆放，多出来的高度给顶部色块和文字。

## 缺素材时问什么（按优先级，一次最多问 3 件）
1. **S5–S7 的 A/B 姿势照**：每场景 2 张，同机位、同光线。这是核心效果，没法凭空编；缺了就降级成单姿势，并且要告诉用户效果会变弱。
2. 两人称呼（{新郎名}/{新娘名} 和拼音）、婚礼日期、地点、厅名、流程时间。
3. BGM。没有的话，问能不能用免版权的抒情曲，140–150 BPM 最贴原网格。
4. 5 张真实风景或建筑照片。缺了用色块 + 报纸条代替，并说明。
5. 英文情话和中文信笺。可以用 copywriting.md 里的默认文案，先给用户过目。
