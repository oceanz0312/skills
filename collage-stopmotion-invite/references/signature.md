# 作者创作习惯 / 签名特征 / 签名特征【签名】（必须保留）
1. 【签名】**3 态 boil 定格**：每 T 换一张重拍帧，3 张循环；中间完全静止，不插值。
2. 【签名】**A/B 姿势闪只用在情绪高峰**：只出现在 S5–S7 三个连续的地标场景（全片中段），其余场景人物只 boil。
3. 【签名】**转场是步进摇镜，不用缓动**：2–3 步，每步 1T，像手动推一张长卷。
4. 【签名】**全片只有一次硬切**：放在从"情话"转到"信息"（流程卡）的地方（27.40s）。
5. 【签名】**首尾砖红呼应**：开场 TV 和结束卡都是砖红 + 橄榄 + 奶油，像打开再合上的信封。
6. 【签名】**一个场景 = 大色块 + 1 张景观/建筑照片 + 1 句话**（v5：色块改成 2–3 层叠放的大撕纸，最多 1 个道具）。
7. 【签名】**英文情话来自古典文学或名人情书**：莎士比亚十四行诗、《第十二夜》、《仲夏夜之梦》、贝多芬《永恒的爱人》；用手写体写（v5：细笔画手写体代替马克笔粗体），每场景换一种颜色。
8. 【签名】**勒索信拼字大标题**只出现一次（WE GOT MARRIED）。
9. 【签名】**复古实物道具**：电视、宝丽来、干花、老爷车、香槟、黑胶、五线谱、红酒杯；都是真实物件抠图，不用插画。
10. 【签名】**涂鸦极少**：全片不超过 6 处，只有黄波浪线、粉斜线圈、粉爱心团。
11. 【签名】**配色冷暖交替**：砖红 → 黄绿 → 黄 → 砖红天 → 黄湖蓝 → 黄绿 → 锈红 → 灰紫雾蓝 → 绿黄粉 → 砖红。
12. ~~字被人压住一角~~（v4 起取消：人物在最上层，但 v5 的 P0 规定文字和人物不重叠）。
13. 【签名】**结尾放 dress code 色卡**：5 个色块横排在顶部。
14. 【签名】**TV 开场**：复古电视开机、频道 OSD"100"、黑屏闪，再三步推镜进屏幕。
15. 【签名】**中文只写实用信息和长信**（信笺、流程、地点），浪漫的话全用英文。
16. 【签名】**人物白边厚、几乎没有投影**，像手账贴纸，不像 PS 合成。
17. 【签名】**报纸剪条当地形**（山脊、斜条），材质混搭。
18. 【签名】**名字做成小标签**（蓝底白字卡 / 纸签），放在人物两侧。

### 什么会打破"原作者做的"错觉（反模式）
- 任何 30fps 的连续缓动（淡入、ease 缩放、平滑摇镜）。
- 每个场景都闪 A/B，或者 A/B 用叠化。
- 加大投影、发光、渐变、3D、粒子、光斑。
- 一个场景放两个以上色块、多张拼照片、满屏涂鸦。
- 用 AI 插画道具、卡通贴纸代替实物抠图。
- 英文用网络流行语或自创口号；中文写情话。
- 草书逐笔写出来（原作没有）；勒索信标题出现两次以上。
- 首尾配色不呼应；中段颜色连续两场同色调。
- 人物脚底在 A/B 之间上下跳。



## v4 有意偏离原作（用户要求）
| 项 | 原作 | v4 | 原因 |
|---|---|---|---|
| 层级 | 草书在人物下面，被人物压住一角 | 人物最上层，什么都不能压人；草书在照片之上、道具之下 | 人物要最清楚，读起来像"贴纸贴在最上面" |
| 人物动作 | 只在 S5–S7 A/B 闪，其余只有细微 boil | A/B 位置明显不同；其余场景每 2T 跳一个头高 | 原作的 boil 在手机上几乎看不出，画面显得死 |
| 文字 | 草书约 0.08W | 160–200px，横跨全宽；勒索信占满上半屏 | 手机竖屏上要一眼能读 |
| 形状 | 有直边色块和矩形照片 | 只用圆、半圆、心、云、团块；照片全部撕边或沿轮廓剪 | 更有手工感，不像 PPT |
| 人物调色 | 原片统一偏暖 | 抠图时统一胶片暖调，黑白照会被着色 | 素材来源不同时保持一致 |
反模式补充：直边矩形色块或照片、人物被字或道具挡住、人物几乎不动、字小到要放大才看清。

## v5 有意偏离原作（用户审片后的要求）
> 先满足 P0，再谈签名。**randomness 只能在 P0 之内变化**。

| P0 | 规则 | 和原片的差别 |
|---|---|---|
| P0-1 | 所有贴纸/道具/涂鸦/文字每帧都完整在画内，人物只允许底边裁脚 | 原片草书和道具会出血 |
| P0-2 | 每场景恰好 A、B 两个位置，A→B→A→B | v4 的单张跳动用 3 个位置 |
| P0-3 | 色块 → 建筑照片 → 人物；建筑居中、轮廓完整；文字道具不压人不压建筑主体 | 原片有报纸条压照片 |
| P0-4 | 色块 = 2–3 层大撕纸叠放，只在最底层 | 原片/ v4 一个几何大圆 + 小撕纸条 |
| P0-5 | 信息内容不被色块盖、互不重叠 | — |

其他 v5 改动：人物脚对齐照片地面线并有接触阴影；全部手写字体（英文细笔画手写、勒索信手写字形、中文霞鹜文楷/马善政）；每场景主色+强调色、风景统一胶片暖调并拉向色板；留白（1 照片 + 1 人 + 1 句 + ≤1 道具）；色块纸纹+颗粒+白纤维撕边；真实复古电视 + 精确玻璃屏 + 对准玻璃推镜；结尾色卡和名牌重做。
