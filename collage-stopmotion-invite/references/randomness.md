# 随机系统：seed / randomness / preset（v5）

> **随机只能在 P0 之内变化。** 每次随机出的版式都要在"全部 boil 态 × A/B 两个位置"上跑一遍 P0 审计（P0-1 越界、P0-2 两位置、P0-3 层级与建筑遮挡、P0-4 色块层数/面积/在底层、P0-5 信息不被盖），任何一条不过就重掷；成片的每个唯一帧再审计一次，违规则 run.py 退出码 3、qa_compare 退出码 1。

所有装饰性的选择在 `init()` 里由 `seed` 一次性生成（`LAYOUT`）；`render(ctx,f)` 仍是帧号的纯函数，同 seed + 同素材逐像素复现。

## 参数（manifest.json → `style`）
| 字段 | 取值 | 默认 | 说明 |
|---|---|---|---|
| `seed` | 整数 | 随机 | `run.py --seed N` 优先；写进 `manifest_seed_N.json`、render_meta、QA JSON |
| `randomness` | low / medium / high | medium | 只缩放装饰范围（倾斜、偏移、撕边抖动、额外元素概率），**不碰 P0 几何** |
| `preset` | retro-warm / morandi / summer-island / film-night | retro-warm | `presets.js`：每场景 [主色, 强调色, 信息卡纸色] + 字体池 + 道具/涂鸦池 |

## randomness 档位
| 档位 | tilt | offset | wobble | extra |
|---|---|---|---|---|
| low | ×0.5 | ×0.5 | ×0.5 | 0 |
| medium | ×1 | ×1 | ×1 | 1 |
| high | ×1.6 | ×1.6 | ×1.5 | 2 |

## 随机项（medium 基础范围）
- **色块（P0-4）**：底色整页 + 1 张强调色大撕纸，`0.45+0.2×extra` 概率再加 1 张主色浅色大撕纸（最多 3 层）。撕法从 `diag`（对角撕，撕线在 0.30–0.62H，两端高差 ±0.06–0.16H）/ `side`（纵向撕，撕线在 0.34–0.66W）/ `arch`（半径 0.62–0.85W 的超大圆弧，圆心在角上）里抽；撕边振幅 7–12px，白纤维边 4–7px。每层画内面积必须 ≥18%。
- **建筑照片（v6）**：近满版位置固定；**遮罩类型随机**（skyline / torn / arch / circle / heart / blob，seed 排序，已用过的类型 +1 往后排，skyline −0.5 优先），遮罩轮廓抖动随机；boil 偏移 ±5px。随机只能在 P0 内：主体必须完整在遮罩里、覆盖率 ≥70%（skyline ≥62%），否则换遮罩/重掷。
- **英文字体**：从预设 `en` 池抽；字号 170–215 × 字体系数，放不下就缩（不低于 118 × 系数），优先按文案原有换行。
- **文字颜色**：在 [墨色, 纸白, 强调色, 强调色加深] 里按背景中位亮度挑对比度最高的，要求 ≥3:1。
- **道具（≤1/场景）**：S2 宝丽来、S3 花束、S9 老爷车固定；S4–S8 有 50% 概率从道具池抽 1 个。位置用拒绝采样：完全在画内、不碰任何文字/信息/建筑主体，可以有 ≤40% 藏在人物身后（人物在最上层，所以不算"道具盖人"）。固定道具放不下时每次重掷缩小 1.2%（最多到 62%）。
- **涂鸦（≤1/场景）**：只在 S2/S4/S6/S8/S9 抽（概率 0.5+0.25×extra），不碰任何内容和人物。
- **人物位置（P0-2）**：A/B 两个位置左右对称，方向（谁在左）和倾斜（2.5–5°）随机；位移量由 P0-1 推出来，不随机。
- **勒索信**：字体从 `ransomFonts`（手写）抽，底块（撕边 / 圆 / 团块）和颜色从场景强调色、纸白、墨色、粉色里抽，字色自动取深或浅，倾斜 3–10°。

## 永不随机【硬锁定】
- 时间轴、节奏、摇镜步帧、硬切帧；boil 帧、A/B 帧、跳动节奏。
- 层级顺序：底纸 → 大撕纸 → 建筑照片 → 信息卡 → 文字 → 涂鸦 → 道具 → 接触阴影 → 人物。
- 两个位置的规则、人物脚线（地面线 / 底边）、人物基准高 0.50H。
- 建筑居中（自动选最小缩放让主体框居中且完整）。
- 最小字号；每场景 1 句话 + ≤1 道具。

## 审计与重掷（`buildLayouts`）
（v6：照片遮罩的主体包含和覆盖率在第 0 步先检查；人物只有在第 8 次重掷之后才开始缩小。）
每场景最多 40 次（attempt 进 seed），记录写进 `render_meta.rerolls`。顺序：
1. 人物两位置能否在画内放下（不行就缩人物，缩到 0.76 还不行就重掷）。
2. 文字对比度 ≥3:1。
3. 放道具和涂鸦（拒绝采样，见上）。
4. 在 land 帧和第一个 A/B / 跳动帧 × 3 个 boil 态上画一遍，用真实绘制调用的包围多边形跑 `auditList`：越界、色块层数/面积/顺序、建筑主体被文字/道具/色块遮挡 >2%、建筑主体超出照片或画面、信息被色块盖、文字/名牌两两重叠、有东西画在人物上面、一帧里出现两个人物贴纸。
5. 渲染时每个唯一帧重新审计（摇镜进行中和 S1 推镜帧不算"落位帧"，只做色块顺序检查）。
