# 背景拼贴法（真实照片 + 手工拼贴元素）

原作的背景不是一张整图，而是**3–6 片材料叠起来的手工拼贴**：真实风景、建筑照片 + 平涂色块 + 撕纸 + 报纸条 + 墙面纹理 + 贴纸。看起来"随手乱贴"，但有几条秩序始终不变。

## 1. 每个场景的背景片数（看帧统计）【估】
| 场景 | 拼贴片（从下到上） | 片数 |
|---|---|---|
| S1 | 纸纹底 → 橄榄块（左上斜边）→ 砖红大块 → 奶油圆弧（右下）→ 黄波浪涂鸦 | 5 |
| S2 | 芥末黄纸纹 → 薄荷绿大圆（左上，被画框裁掉）→ 粉爱心团 | 3 |
| S3 | 芥末黄 → 薄荷绿圆 → 牛皮纸撕纸信笺（毛边，斜 ±2°） | 3 |
| S4 | 砖红天 → 橙日半圆 → **报纸剪条做山脊** → 蓝紫雪山照片窄带 → 山林照片（主）→ 底部草绿撕纸条 | 6 |
| S5 | 芥末黄 → 湖蓝大圆 → 城市夜景照片（上沿撕边）→ 海面照片 → 底部手写信纸条 | 5 |

规律：**风景场景（S4–S8）5–6 片，信息场景（S2/S3/S9）3 片**。

## 2. 照片怎么"剪"【估，参考帧观察】
- **不用整张矩形照片**。每张真实照片至少有一条边做了处理：
  - 撕边：上沿用不规则毛边，带白色纸纤维，宽 3–6px@720；
  - 沿轮廓抠：建筑、塔、椰树按轮廓抠出来，天空换成色块或另一张云图；
  - 窄条：照片裁成横条（S4 雪山）或竖条（S6 墙、S7 老楼），只露一部分。
- **局部、出血**：照片几乎都从画面左右边缘出血，只露出 60–90% 的主体；地标顶部可以被裁掉。
- **倾斜**：大照片 0°（地平线保持水平）；小条、报纸条 ±3–20°。
- **错位**：相邻两片照片之间故意留一道 5–20px 的缝或重叠，露出下面的色块。

## 3. 受控随机（实现规则）
| 参数 | 范围 | 级别 |
|---|---|---|
| 片数 | 风景场景 4–6 片，信息场景 2–3 片 | 【签名】 |
| 大照片旋转 | 0°（±0.5°） | 【硬锁定】 |
| 小条 / 报纸条旋转 | seed 随机 ±3–20°，同一场景内正负号交替 | 【可调】 |
| 片间偏移 | 5–20px@720，露出底色 | 【可调】 |
| 大色块 | 每场景 1 个（圆或带斜边的大块），中心在左上或右上，半径 0.35–0.55W，至少 20% 出画框 | 【硬锁定】 |
| 撕边 | 用 1D 噪声生成轮廓，振幅 4–10px、周期 15–40px，加一圈 2–4px 白纤维 | 【可调】 |
| 层间重叠 | 照片可以压色块；色块永远不能压照片的主体（地标、建筑） | 【硬锁定】 |

**保持不乱的秩序**【硬锁定】：
1. 地平线 / 主照片的水平线保持水平；
2. 主照片只有 1 张（另外最多 1 张辅助窄条）；
3. 大色块只有 1 个；
4. 背景片都在人物层下面，人物下半身后面的区域要"干净"（单一照片或色块）；
5. 文字带后面要有足够对比（色块或天空），不放在照片的复杂细节上。

## 4. boil 怎么重新随机【实测】
用相位相关测了相邻 boil 态之间每块区域的位移：
| 元素 | 每态位移 | 结论 |
|---|---|---|
| 风景照片（S8 椰树海滩、S4 山林） | (11,8)、(4,10) px@720 | **跟着 boil 抖** |
| 报纸山脊（S4） | (2,7) px | 小幅抖 |
| 道具（车、香槟瓶） | (−10,−6)、(4,7) px | 抖 |
| 大色块圆、粉撕纸 | (0,0)，但纹理相关性只有 0.5–0.7 | **位置不动，只换纸纹** |
| 天空色块 | (0,0)，相关性 0.27 | 只换纹理 |

实现：`seed = hash(sceneId, pieceId, boilState)` → 每片照片和小条 dx,dy ∈ [−12,12]px@720（1080 宽 ±18px），rot ∈ [−0.8°,0.8°]；色块的几何形状固定，纸纹偏移随 boilState 换；撕边轮廓**不要**每态重新生成（会显得在"沸腾"，原作没有）【估】。

## 5. 背景照片素材约束
- **必须是真实地点**：自然（山、海、花田）、城市夜景、地标、有特色的建筑；最好是新人自己去过的地方，或者婚礼所在城市。
- 每张至少 1080px 短边；地标要有清晰的轮廓，方便抠图；天空简单（纯蓝或干净的云），好替换。
- 调色：整体饱和度 −10~15%，往暖色偏（色温 +5），高光压低，加 3–5% 颗粒；照片色调要和场景色块互补（黄色块配蓝色调照片，红色块配蓝绿色照片）。
- 不要：带水印、带人群的正中主体、HDR 过度、夜景噪点很重的手机照。
- 缺失时：用场景色块 + 1 条报纸条 + 1 张公版纹理（水泥墙、旧纸）代替，并在交付说明里写清楚。
