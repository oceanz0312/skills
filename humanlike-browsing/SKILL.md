# 拟人化浏览规则

## 0. 先决条件（比任何随机延迟都重要）
- 一个账号 = 一个固定浏览器 Profile（保留 Cookie/登录态）+ 一个固定出口 IP。不清 Cookie 重登，不中途切换代理。
- 浏览器时区、语言与出口 IP 所在地一致；用有界面的真实 Chrome，不用 headless。
- 页面一打开就被拦/弹验证 → 是 IP 或指纹问题，停止并报告，不要靠"放慢"硬试。

## 1. 节奏
- 页面加载后先停 2–6 秒；内容页按篇幅"阅读" 5–20 秒。
- 两次点击间隔 0.8–3 秒随机；约 10% 概率额外停 3–8 秒。
- 不用固定间隔或均匀分布；短停顿多、长停顿少。

## 2. 鼠标
- 点击前先移到目标附近（1–2 次移动），停 0.1–0.4 秒再点。
- 点击点在元素内随机偏移，不总点正中心。
- 约 10–15% 概率先悬停无关元素再去目标。
- 工具支持轨迹时用曲线移动，长距离允许轻微越过再修正。

## 3. 输入
- 不粘贴、不直接赋值；逐字或分小段输入。
- 字符间隔 60–250ms 波动；每 5–15 字停 0.3–1.5 秒。
- 偶尔（≤2%）打错再退格；密码、验证码、金额、地址禁止故意打错。
- 输入前先点击聚焦输入框。

## 4. 滚动
- 每次约 1/3–2/3 屏，多次进行，间隔 0.5–2 秒。
- 不一次跳到底；偶尔往回滚一点。

## 5. 频率上限（宁慢勿快）
- 同一站点每分钟 ≤ 6–10 个有效动作；连续 15–25 分钟后休息 ≥ 5 分钟。
- 发帖/关注/私信/下单/提交表单：每小时 ≤ 5–10 次，每天设上限；新账号头几天减半。
- 同一 IP 不并行操作多个账号；用户当地 1:00–7:00 不做批量操作。

## 6. 立即停止并交还用户
- 出现 CAPTCHA、Cloudflare/Turnstile、"异常活动"、短信或设备验证、登录风险提示。
- 不破解或绕过验证；截图说明在哪一步出现。
- 同一操作失败 2 次就停，不反复重试。

## 7. 边界
- 只在用户本人账号、用户明确要求的任务里使用。
- 遵守目标站条款；明确禁止自动化时先告知用户风险。
- 拟人化只能降低误判，不能保证不被封；高价值账号优先手动或用官方 API。

## 给浏览器子任务派单时
把本规则的要点（节奏、鼠标、输入、滚动、频率、遇验证即停）原样写进派单说明，因为执行浏览器操作的子任务看不到这份 skill。
