# 签名与创作习惯
## 【签名】必须保留
1. 弧线锁位：35 镜中可检测的 26 镜弧顶 y 中位 0.485、相邻跳变 P90 0.04【实测】。
2. 尺度跳跃：宇宙 → 显微 → 器物 → 画作交替出现，不连续两镜同类（timeline.md 题材列）。
3. 加速曲线：0.52–0.6s → 0.32–0.44s → 0.24–0.28s → 0.20s，最后一镜 4.24s 长尾【实测】。
4. 字不动，世界动：一个词组跨 4–12 镜位置字号完全不变，在切点上硬切换（f218/f267/f312/f394）【实测】。
5. 首尾呼应：开场与片尾都是大气层光弧，片尾上摇露出日出光带【看帧】。
6. 明暗闪：黑顶镜头与亮纯色顶镜头穿插（约 7:3）。
## 【从不做】
叠化/擦除/闪白转场；字幕动画（逐字、弹跳、淡入）；人物脸；UI 截图；镜头抖动；弧线偏离中心；同色镜头相邻。
## 反模式（出现就不像）
弧线在不同镜头里忽高忽低；节奏匀速；文字压在纹理上；片尾加一堆标语；配色变成冷蓝科技风/霓虹。
