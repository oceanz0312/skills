# 中文 AI 工具种草爆款推文风格

## 风格基线（数据来自同类账号 2025-12 之后约 320 条原创帖的统计）
- **长度**：中位数约 150 字，正文分 5 到 7 行。每行一句话，行与行之间常空一行。
- **节奏**：短句为主，语气口语化。开头先放一句情绪或反常识判断，中间一句一个信息点，结尾放行动号召（CTA）。
- **高频词**："真的"（约 30% 的帖子出现）、"我发现"、"兄弟们"、"牛逼"、"万万没想到"、"我的天"、"卧槽/我靠"（只在最强情绪时用）。
- **标点**：情绪高点用连续的"！！！"或"？？？"，约 15% 的帖子有。用「」包住概念词，用"······"表示停顿或懵了。
- **数字**：约 78% 的帖子带数字，比如播放量、star 数、时长、成本、省下的百分比、价格。数字是可信度的主要来源。
- **emoji**：很少用，只有约 4%。偶尔用 ⬇️ 指向评论区或下文，🤣 用来自嘲。

## 步骤

### 第 1 步：选模板
| 模板 | 适用场景 | 核心卖点 |
|---|---|---|
| A 提示词技巧帖 | 有一个可复用的用法 | 反常识的"骚操作"，读者马上能试 |
| B 工具推荐帖 | 发现了新产品或开源项目 | 冲击力加演示数据 |
| C 个人故事帖 | 求职、转行、亲友经历 | 共情加"我是怎么解决的" |
| D 变现方法帖 | 讲赚钱路径或案例 | 低成本、可验证的一单 |

### 第 2 步：写钩子（第一行，不超过 30 字）
常用开头：
- 反常识型：「真的会用 AI 的人，都在故意××」「不要直接让 AI ××，结论多半是假的」
- 发现型：「发现一个骚操作：」「我发现了一个××的站」「这应该是我看过××的最佳实践」
- 惊叹型：「我的天！」「万万没想到，」「啊？？？还有这种××？？」
- 场景型：「半夜两点刷到××」「昨天和做独立开发的朋友吃饭，他说……」
- 号召型：「兄弟们！××的福音来了！！」

### 第 3 步：写正文（按模板骨架，下面的例子都是改写的示意）

**A 提示词技巧帖**
1. 钩子：大多数人这样用 AI，得到的全是正确的废话。
2. 原理：一句话讲清机制，可以借一个权威，比如"某论文讲的是 Verify First"。
3. 做法：让 AI 先批判你的烂方案，再生成；给出可复制的提示词片段。
4. CTA：完整提示词放在评论区。

例子骨架：
- 「别让 AI 直接分析 → 让它设对照组、正反两面辩证 → 这样写：…… → 结论会有观点」
- 「先写一个烂方案 → 问 AI 错在哪 → 再让它重写 → 质量翻倍」
- 「我记录了两天时间 → 丢给模型分析 → 它指出我××的问题 → 分析和生图的提示词在评论区」

**B 工具推荐帖**
1. 钩子：情绪加判断，比如"××行业要洗牌了"。
2. 实测：我用它做了××，输入是什么、输出是什么，带上具体数字（几秒、几条、几 star）。
3. 亮点：最多列 3 条，或者一句"它把××从××变成了××"。
4. 降门槛：已开源、GitHub 能找到、成本几块钱。
5. CTA：链接或地址，加一句"赶紧点 star 或收藏"，然后 @ 官方账号。

例子骨架：
- 「我靠！！一张照片加一条 26 秒短视频，用××复刻出了几乎一样的片子 → 素材效率提升××倍 → 已开源，地址⬇️」
- 「24 小时 5K star 是什么概念 → 团队负责人才 18 岁 → 对比一下硅谷团队要多久 → 项目地址」
- 「Codex 半小时提取了 150+ 条视频逐字稿 → 只用了周额度的 0.5% → 以前要花 ×× 元找人做 → 开源 skill 地址」

**C 个人故事帖**
1. 场景：某个具体时间点刷到或遇到一件事。
2. 联想：想到了身边某人，或者去年的自己。
3. 冷观点：比如"找不到工作是必然的，第一……第二……"。
4. 解法：让对方把 JD 发来，用 AI 做了××，结果怎样。
5. 收尾：一句价值观，或者"方法放在评论区"。

例子骨架：
- 「半夜刷到哭诉求职的视频 → 想起学冷门专业的妹妹 → 市场要的是能解决问题的人 → 我用 AI 帮她拆了 JD → 步骤如下」
- 「一年前我还在工地 → 一个月转行 → 三个月接到第一单 → 我只做对了一件事：××」

**D 变现方法帖**
1. 钩子：发现一个"羊毛"或"生意"。
2. 路径：两三种变现方式，每种给出单价或数字，比如"一单 200，我验证过"。
3. 成本：工具组合加成本，比如"域名 10 块"。
4. 风险或反思：一句即可，可选。
5. CTA：完整方法论放在文章或评论区。

例子骨架：
- 「A 工具加 B 工具简直绝配 → 第一种是流量收益，第二种是给商家定制、一单 ××（已验证）→ 教程⬇️」
- 「把一个小生意当商业课题研究 → 给出数据和分层定价 → 核心逻辑一句话总结」

### 第 4 步：写 CTA（只选一个主 CTA）
- 「完整提示词 / 项目地址在评论区⬇️」
- 「需要的自取～」「建议先收藏，之后找不到了」
- 「把这篇丢给 AI，让它给你推荐阅读路径」（适合合集帖）
- @ 项目方或相关大佬，可以顺带互动，但不能伪装成中立评价

### 第 5 步：自检清单
- [ ] 第一行不超过 30 字，有情绪或反常识点
- [ ] 每行只说一件事，全帖 5 到 8 行，总长 100 到 300 字（长文例外）
- [ ] 至少有 1 个**真实、可核验**的数字（自己测出来的，或者有出处）
- [ ] 至少给 1 个读者马上能用的东西：提示词、步骤、链接、开源地址
- [ ] 全帖"！！！"最多出现 2 处，"牛逼 / 卧槽"最多 1 处，避免整篇都在喊
- [ ] 只有一个 CTA，而且确实兑现（评论区里真的有提示词或链接）
- [ ] 没有"取代 OpenAI""不用就会死""月入过万"这类无法证实的断言
- [ ] 商业合作已标注

## 真实性与广告标注（必须遵守）
- 只写亲自验证过的结果。截图和数据要能复现；没验证过的写"据官方称"或"我还没测"。
- 收入、涨粉、学员成果不要编造，也不要夸大；不要渲染"再不学就被淘汰"这类焦虑。
- 拿了报酬、免费额度或返佣的，在开头或结尾标注「广告 / 合作 / 含推广链接」，并遵守平台和当地法规。
- 风险要提一句：比如中转站、爬虫、"无视防爬"这类工具，可能涉及合规或账号安全问题。
