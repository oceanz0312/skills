# 背景拼贴（通用）：色块、撕纸、照片遮罩规则与 v8 相同；纹理和遮罩池由风格包决定（packs.js 的 tex / masks / photoFilter / photoBorder）。

# 背景拼贴法（v6：大撕纸色块 + 一张近满版不规则遮罩的建筑照片）

## v6 照片层（替代 v5 第 3 条的居中卡片）
- 照片片 = x −40、y 330、宽 W+80、高 H−290（左右下出血），按主体框自动居中裁切（缩放 1–1.7）。
- 遮罩（`maskPts`）：
  - `skyline`：在 160px 缩略图上从顶行按天空色泛洪，得到逐列天际线（中值平滑），映射回照片坐标做上边；天空被剪掉，后面的色块透出来。只有检测到天空（平均天空高 8–65%）时才可选。
  - `torn`：顶边是一条撕纸斜线（两端 0–16% 高），左右下出血。
  - `arch`：拱门顶；`circle`：大圆（半径 0.62W 级，两侧出血）；`heart`、`blob`：大心形、有机团块。
- 主体检查：主体框四角（内缩 4%）+ 顶部中点必须在遮罩里；不在就把遮罩以底边为轴向上拉伸（最多 1.8 倍），还不行就换下一种遮罩；都不行就重掷。
- 覆盖率：遮罩多边形裁到画框后的面积 ≥70%（skyline ≥62%）。
- 边：12px 纸白描边 + 8px 柔投影，像剪下来贴在色块上。调色仍是统一胶片暖调 + 场景主色 soft-light。

> P0-3 / P0-4：色块只在最底层，每帧 2–3 层大纸叠放，每层画内面积 ≥18%；建筑照片居中、轮廓完整、不被色块盖。下面"v4 及以前"的小撕纸条、报纸条、地面条在 v5 里**全部删除**（牛皮癣）。

## v5 做法
1. **底纸**：场景主色铺满整页 + 皱纸纹理（multiply 30%）+ 细颗粒。
2. **大撕纸 1–2 张**：强调色一张，可选一张主色浅色（主色和纸白 58:42 混）。撕法：对角撕 / 纵向撕 / 超大圆弧（见 randomness.md）。每张：白色纸纤维底边（4–7px，带轻投影）+ 毛刺纤维线 + 色纸 + 纸纹 26% + 颗粒。
3. **建筑照片**：992×1110 撕边片，白纸边 5px，统一胶片暖调 `sepia(.22) saturate(.72) contrast(.94) brightness(1.04)`，再 soft-light 30% 场景主色 + multiply 10% 暖橙。主体框居中、完整。
4. **信息卡**（S3 信笺、S9 流程卡、S10 日期卡）是内容，不算色块，画在照片层之上。

# 背景拼贴法（真实照片 + 手工拼贴元素）

原作的背景不是一张整图，而是**3–6 片材料叠起来的手工拼贴**：真实风景、建筑照片 + 平涂色块 + 撕纸 + 报纸条 + 墙面纹理 + 贴纸。看起来"随手乱贴"，但有几条秩序始终不变。

## 1.5 v4：不要方块
- 色块只用大圆、半圆、心形、云朵、有机团块，边缘用 3 组正弦叠加做手剪抖动（振幅约 2% 半径）。
- 照片和纹理一律撕边（四边都撕，四角剪掉）或沿轮廓剪成团块（`cut: "torn" | "blob"`，由 seed 决定），不出现直边矩形。
- 撕边外圈一律加 4px 白纸纤维边。
- 道具、贴纸各自随机倾斜、缩放、偏移（见 randomness.md）。

## 2. 照片怎么"剪"【估，参考帧观察】
- **不用整张矩形照片**。每张真实照片至少有一条边做了处理：
  - 撕边：上沿用不规则毛边，带白色纸纤维，宽 3–6px@720；
  - 沿轮廓抠：建筑、塔、椰树按轮廓抠出来，天空换成色块或另一张云图；
  - 窄条：照片裁成横条（S4 雪山）或竖条（S6 墙、S7 老楼），只露一部分。
- **局部、出血**：照片几乎都从画面左右边缘出血，只露出 60–90% 的主体；地标顶部可以被裁掉。
- **倾斜**：大照片 0°（地平线保持水平）；小条、报纸条 ±3–20°。
- **错位**：相邻两片照片之间故意留一道 5–20px 的缝或重叠，露出下面的色块。

## 3. 受控随机（实现规则）
| 参数 | 范围 | 级别 |
|---|---|---|
| 片数 | 风景场景 4–6 片，信息场景 2–3 片 | 【签名】 |
| 大照片旋转 | 0°（±0.5°） | 【硬锁定】 |
| 小条 / 报纸条旋转 | seed 随机 ±3–20°，同一场景内正负号交替 | 【可调】 |
| 片间偏移 | 5–20px@720，露出底色 | 【可调】 |
| 大色块 | 每场景 1 个（圆或带斜边的大块），中心在左上或右上，半径 0.35–0.55W，至少 20% 出画框 | 【硬锁定】 |
| 撕边 | 用 1D 噪声生成轮廓，振幅 4–10px、周期 15–40px，加一圈 2–4px 白纤维 | 【可调】 |
| 层间重叠 | 照片可以压色块；色块永远不能压照片的主体（地标、建筑） | 【硬锁定】 |

**保持不乱的秩序**【硬锁定】：
1. 地平线 / 主照片的水平线保持水平；
2. 主照片只有 1 张（另外最多 1 张辅助窄条）；
3. 大色块只有 1 个；
4. 背景片都在人物层下面，人物下半身后面的区域要"干净"（单一照片或色块）；
5. 文字带后面要有足够对比（色块或天空），不放在照片的复杂细节上。

## 4. boil 怎么重新随机【实测】
用相位相关测了相邻 boil 态之间每块区域的位移：
| 元素 | 每态位移 | 结论 |
|---|---|---|
| 风景照片（S8 椰树海滩、S4 山林） | (11,8)、(4,10) px@720 | **跟着 boil 抖** |
| 报纸山脊（S4） | (2,7) px | 小幅抖 |
| 道具（车、香槟瓶） | (−10,−6)、(4,7) px | 抖 |
| 大色块圆、粉撕纸 | (0,0)，但纹理相关性只有 0.5–0.7 | **位置不动，只换纸纹** |
| 天空色块 | (0,0)，相关性 0.27 | 只换纹理 |

实现：`seed = hash(sceneId, pieceId, boilState)` → 每片照片和小条 dx,dy ∈ [−12,12]px@720（1080 宽 ±18px），rot ∈ [−0.8°,0.8°]；色块的几何形状固定，纸纹偏移随 boilState 换；撕边轮廓**不要**每态重新生成（会显得在"沸腾"，原作没有）【估】。

## 5. 背景照片素材约束
- **必须是真实地点**：自然（山、海、花田）、城市夜景、地标、有特色的建筑；最好是新人自己去过的地方，或者婚礼所在城市。
- 每张至少 1080px 短边；地标要有清晰的轮廓，方便抠图；天空简单（纯蓝或干净的云），好替换。
- 调色：整体饱和度 −10~15%，往暖色偏（色温 +5），高光压低，加 3–5% 颗粒；照片色调要和场景色块互补（黄色块配蓝色调照片，红色块配蓝绿色照片）。
- 不要：带水印、带人群的正中主体、HDR 过度、夜景噪点很重的手机照。
- 缺失时：用场景色块 + 1 条报纸条 + 1 张公版纹理（水泥墙、旧纸）代替，并在交付说明里写清楚。
