# 素材数量与质量规范（v4 · 预检 `scripts/precheck_assets.py` 用同一套数字）

## 1. 数量：最少 / 推荐 / 最佳效果
"最少" = 低于它预检就报"不够"（用户坚持也能做，但会复用照片、用纯色块顶替）；"推荐" = 每个槽位都有专属素材；"最佳" = 再多一些备选，让 AI 挑最好的。

### invite-classic（锁定婚礼请柬，S1–S10，38.43 秒）
| 素材 | 最少 | 推荐 | 最佳效果 | 来源（哪些槽位要） |
|---|---|---|---|---|
| A/B 对（同地点同衣服连拍 2 张、换站位） | 3 对（6 张） | 3 对（6 张） | 4 对（8 张，多 1 对备选） | S5 / S6 / S7 各 1 对，A/B 闪只在这三场 |
| 双人全身单张 | 2 张（其余复用） | 5 张 | 7 张 | S2 / S4 / S8 / S9 / S10 各 1 张 |
| **人物照合计** | **8 张** | **11 张** | **14–15 张** | |
| 风景 / 建筑照 | 3 张（其余场景退化为纯色块） | 5 张 | 7 张 | S4 自然风景、S5 城市夜景/水边、S6 建筑街道、S7 地标+天空、S8 海边 |
| 道具照 | 0（全部内置） | 0 | 0 | 电视、宝丽来、干花、老爷车、香槟、黑胶都是内置 |
| BGM | 1 首 ≥38.5 秒 | 1 首，副歌明显 | 1 首，BPM 147 左右（T≈12.25 帧）不用伸缩 | 全片 |
| 文案·必填 | 两人名字（中文+拼音）、日期、城市、厅名、流程时间 | 同左 | 同左 | S1 名字行、S9 流程卡、S10 信息/名牌 |
| 文案·可选 | 0（用默认并标占位） | 给亲友一段话（≤13 行 ×14 字） | + 4 句英文短句（S4–S8，每句 ≤24 字符）+ 结尾一句 | S3 信笺、S4–S8 草书、S10 粉纸条 |

### 自由模式（其它 5 个风格包；按片长）
片长决定中间场景数：30 秒 ≈ 5 个，38 秒 ≈ 6 个，60 秒 ≈ 9–10 个；外加开场、结尾各 1。每张风景最多用一次。
| 素材 | 最少 | 推荐（38 秒） | 最佳效果（38 秒；60 秒再 +50%） | 说明 |
|---|---|---|---|---|
| 人物照合计 | 2 张 | 6 张（含 2 组 A/B 对） | 10 张（含 3 组 A/B 对） | A/B 对优先放进风景场景做 ab/stutter 闪；单张用 jump |
| 风景 / 场景照 | 1 张（<2 张时以 solo/note/list 为主） | 3 张 | 6 张（= 中间场景数，每场一张） | |
| 道具照 | 0 | 0 | 0–2（抠好的道具/电视，可选） | 贴纸涂鸦全程序化生成 |
| BGM | 1 首 ≥30 秒 | 30–45 秒 | 和片长一致、鼓点清楚 | |
| 文案 | 一句话场合+情绪 | + 名字 / 日期 / 地点 | + 想写的 2–4 句话（原话一字不改） | 其余文字 AI 按故事板写 |

## 2. 质量规则（预检逐张检查）
| 检查 | 不合格（剔除，要求换） | 警告（能用，提示） |
|---|---|---|
| 人物分辨率 | 长边 <1000px | 长边 <1500px |
| 风景分辨率 | 短边 <720px | 短边 <1080px |
| 清晰度（拉普拉斯方差，缩到 800px 算） | 人物 <24 / 风景 <16（明显糊） | 人物 <60 / 风景 <40 |
| 人物完整（姿态关键点） | 腰/髋以下被裁的半身照；人被照片左/右/上边裁掉（只允许底边） | 只到大腿：只能贴底边放；多人时有人被挡 |
| 抠图完整（有 `cut/*.mask.png` 时，跑 `person_check.py` 的 P0-6） | 缺躯干、缺 ≥2 个肢体、漂浮碎片、边缘裁切 | 完整人数少于预期 |
| 重复 | 几乎一样的照片只保留评分高的一张（dHash 差 ≤6） | — |
| 风景构图 | — | 宽高比 <1.3（不够横、不够远） |
| A/B 对 | 文件名 `*_A`/`*_B` 优先；否则背景相似度 ≥0.6 自动配对 | 同机位、同衣服仍需人工看一眼 |
其它照片建议：单一主体（一人或一对，别带路人）、背景简单和人物对比明显、原图（不要截图/聊天压缩图）、偏暖低对比、婚纱别过曝。

## 3. 选片规则
- 评分 = 清晰度 + 分辨率 + 人物完整度 − 警告数。
- invite-classic：文件名带 `S<n>_` 的照片放回原场景；其余 A/B 对按顺序放 S5→S7，单张最好的给 S4、S10，然后 S8、S9、S2；风景依次 S4–S8。缺的单张复用，缺的风景用纯色块。
- 自由模式：A/B 对配风景做 place 场景；单张补没有 A/B 的 place 场景、开场、solo/list/ransom、结尾。
- 太多：超出槽位的按评分丢弃，报告逐张写清楚丢了哪张、为什么。
- 文案缺了：必填项列出来问用户；可选项给默认值，报告里标〔占位〕。
