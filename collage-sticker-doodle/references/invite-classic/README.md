# 拼贴手账定格风 · 请柬视频模板（v8）

> **v8**：中文全部用马善政手写体（深黑加粗墨色）；人物不可被任何元素遮挡（逐帧逐像素审计，被盖 >0 像素即 FAIL）；含 v6 近满版不规则遮罩背景与 v7 人物完整性检查。

## ⛔ P0 硬规则（任何随机参数都不许破坏；渲染器逐帧审计，违反即判定 FAIL）
| 规则 | 内容 | 怎么保证 |
|---|---|---|
| **P0-1 不越界** | 每个贴纸、道具、涂鸦、文字、卡片、名牌、风景照片在**每一帧**（含跳动位置和 boil 抖动）都完整落在画面内。**唯一例外**：人物的脚/腿可以被**底边**裁掉（像原片 S4/S7）；人物不许越出左、右、上边。 | 人物位置按"最坏旋转+最大抖动"算包围盒；版式在全部 boil 态×两个位置上审计，越界就重掷；成片每个唯一帧再审计一次 |
| **P0-2 恰好两个人物位置** | 每个有人的场景只有 A、B 两个位置，按网格 A→B→A→B 交替。两张照片：A 照在 A 位、B 照在 B 位；一张照片：同一张在 A、B 两位之间跳。永远不出现第 3 个位置。boil 微抖只是底层小抖动，不算新位置。 | `L.pos` 只有 2 项；QA 检查每场景位置集合 = {0,1}，且位置 = 事件序号 mod 2 |
| **P0-3 层级**（v6：主体框必须完整落在照片遮罩多边形内；skyline 遮罩只验主体底边，因为建筑像素本来就不是天空） | 从下到上：整页大色块 → 建筑/风景照片 → 人物。有建筑/地标时居中放置，**完整轮廓可见**，绝不被色块盖住。没有建筑时人物直接站在色块上。视觉优先级：人物 > 建筑 > 色块（色块只是背景装饰）。道具和文字不许盖住人物，也不许盖住建筑主体。 | 绘制顺序固定；建筑主体框（`landscape_subject`）必须完整落在照片片内且居中（自动选最小缩放让主体居中）；QA 统计主体被文字/道具/色块遮挡的比例（>2% 失败）和压在人物上的元素数（>0 失败） |
| **P0-4 色块** | 大面积，每帧最多 2–3 层，像几张大纸叠在一起；不许满屏小碎块（"牛皮癣"）。色块**只在最底层**，绝不压在内容上。 | 底色整页 + 1–2 张大撕纸（对角撕 / 侧边撕 / 超大圆弧）；QA：层数 ≤3、每层画内面积 ≥18%、所有色块都在第一件内容之前绘制 |
| **P0-5 信息不被盖** | 信息内容（流程、信笺、所有文字、名牌、实物道具、请柬卡）绝不被色块盖住，信息之间也不互相压。 | 结构上色块先画；QA 检查色块压信息、文字/名牌两两重叠 |
| **P0-6 人物完整（v7）** | 每个人物贴纸里的人必须是完整的：不许只剩头+手臂、缺躯干/肢体、有漂浮碎片，也不许在左/右/上边被裁（只允许脚/腿被画面底边裁）。抠图阶段和成片阶段各查一次。 | cutout.py 抠完即跑 `person_check`（MediaPipe 多人姿态 + mask 连通性 + 边缘裁切），失败自动换 rembg 模型/合并参数，全失败退出码 3 → 换素材；run.py `--person-check` 在每场景落位帧 + 每个 A/B / 跳动帧把源图关键点按该帧真实贴纸变换映射到成片上，必须落在画出的贴纸像素里，违规退出码 4；qa_compare 的 `P0-6_person_complete` 失败 → 不能交付 |
| **P0-7 人物永不被遮挡（v8）** | 任何一帧里，人物贴纸的任何像素都不许被任何东西盖住：道具、文字、涂鸦、照片、色块、胶带、花、电视机框/玻璃反光、转场都不行。人物永远最后画（只有全片 4% 颗粒在最上层）。S1 电视屏里的 S2 情侣也是在电视框、反光、标题、名字之后单独再画，可以"探出"屏幕，但不被裁也不被盖。 | 像素级：run.py 对每个唯一帧关掉颗粒重画一次并记录每次人物 drawImage 的完整变换，再把贴纸单独画出来；贴纸不透明像素与成片像素差 >3 的个数必须 = 0，否则 `P0-7 person occluded Npx` → 退出码 3；qa_compare `P0-7_no_occlusion` |

**randomness 只在 P0 之内变化**：seed 可以改形状、角度、字体、颜色、道具位置，但每次随机后都要过 P0 审计，不过就重掷（每场景最多 40 次）；40 次都不过 → 渲染退出码 3。

## 这是什么
对一条 38.43 秒婚礼请柬参考片（30fps）的逐帧拆解。**节奏是模板，画面是填空**：整片挂在 T = 12.25 帧（0.408s）的定格时钟上，事件帧 `round(3.4 + 12.22k)`。用户换人物、风景/建筑照片和文案；`seed` 决定装饰细节。

标签：【硬锁定】不改；【可调】给定范围内调；【签名】原作者习惯，必须保留；【随机】由 seed 决定；【实测】从原片量出；【估】目测；【偏离】有意和原片不同。

## 工作流程
1. **素材清单**：照 `assets/manifest.example.json` 写 `manifest.json`。每个风景场景给 `landscape_subject`（建筑主体框，源图归一化 `{u,v,w,h}`）和 `landscape_ground`（照片片里地面线的高度比例，人物脚落在这里）。`style` 写 `preset` / `randomness` / `seed`。
2. **抠图 + 人物完整性（P0-6 源图侧，必做）**：`python scripts/cutout.py in.jpg cut/S5_A.png [--expect 2]`（自动选模型、两人合成一张贴纸、统一胶片暖调，同时输出 mask 和 `.check.json`）。抠完立即跑 `scripts/person_check.py`：照片里每个被收进贴纸的人，可见的肩/髋/肘/膝/踝都必须在 mask 里；缺躯干或 ≥2 个肢体关节、漂浮碎片、在原图上/左/右边被裁 → 依次换 u2net_human_seg / isnet-general-use / birefnet-portrait / u2net 和合并距离重抠；全部失败退出码 3 → **换一张素材**，再不行就告诉用户。"完整人数 < expect" 只是 WARN（姿态模型对深色西装/老照片会漏检），必须在拼图里人工确认。
3. **电视屏**：`python scripts/tv_screen.py cut/props/tv.png --json cut/props/tv.screen.json --preview tv_check.jpg`，看一眼预览（青色圆角框应该正好贴住玻璃）；manifest 里 `S1.slots.prop_tv_screen` 指向这个 json。
4. **校验**（v6 另查：主体框宽度能否放进竖版满版裁切、主体是否贴原图顶边、照片高度是否够满版）：`python scripts/validate_manifest.py manifest.json`。检查分辨率、文字长度、姿势舒展度、A/B 同机位、**风景是否远景/有纵深**（画幅、地平线、细节密度，近景局部会 WARN）、**每场景 ≤1 个道具**、**所有字符在手写字体里都有字形**（fontTools）、BGM。有 REJECT 先解决。
5. **定时钟**：T 与 12.25 差 ≤0.4 帧用原网格，否则按 timeline.md 伸缩；用原片音轨就从第 0 帧对齐。
6. **渲染**：把 render_template 放到项目根目录 `render/`（含 person_check.py），字体放 `fonts/`，然后 `python render/run.py all frames --seed N --person-check --person-sheet person_check_sheet.jpg`。run.py 在每个唯一帧的真实绘制调用上做 P0 审计，写进 `render_meta`；有 P0 违规退出码 3，字形缺失退出码 2。同 seed 逐像素复现。
   `ffmpeg -framerate 30 -i frames/%05d.png -i bgm.mp3 -c:v libx264 -pix_fmt yuv420p -crf 18 -shortest out.mp4`
7. **成片人物检查（P0-6 成片侧，交付前必做，不能跳过）**：`--person-check` 对每场景落位帧 + 每个 A/B / 跳动帧导出"只画人物"的图层，把源图姿态关键点按该帧真实的贴纸位置/缩放/旋转/抖动映射到成片上：落在画外下方 = 允许；落在左/右/上边外 = FAIL；落在画面内却不在贴纸像素上 = 缺身体 FAIL。同时查贴纸碰左/右/上边、碎块。在贴纸单独图层上重跑姿态只作 WARN。违规 → 退出码 4。`person_check_sheet.jpg` 是逐场景拼图（绿=通过，黄=有警告，红=失败，蓝点=映射关键点，红点=缺失关键点）：**交付前必须由人或 agent 逐行看一遍**，黄框（漏检警告）尤其要确认两个人都是完整的。
8. **QA**（v6 多一项 `V6_photo`：每场景遮罩类型、最小画内覆盖率、全片不同遮罩数）：`python scripts/qa_compare.py out.mp4 --ref ref.mp4 --meta render_meta.json --json qa.json`。P0-1…P0-7、字形全覆盖任何一项失败（没带 --person-check 跑出的 meta 会让 P0-6 直接失败） → 退出码 1，这片不能交付。另外看：静止帧差 <0.2、网格步长 12.25±0.1、最大残差 ≤1.5 帧、A/B / 跳动位移 ≥ 头高。最后自己逐场景看帧，对着 P0 表核一遍。
8. **交付**：mp4（+720p <10MB）+ 对比拼图 + QA JSON + seed + WARN 清单。

- **boil**：事件帧 `round(3.4 + 12.22k)`，3 态循环；两次事件之间完全静止。boil 是底层小抖动（人物 ±6–16px、±1.2°），不算位置。
- **人物动作【硬锁定】（P0-2）**：每场景恰好 A、B 两个位置。A/B 场景（S5–S7）每 1T 换一次（A 照 ↔ B 照）；单张场景每 2T 跳一次（同一张在 A、B 间跳）。A、B 左右对称错开（风景场景最多 ±0.20W，其余 ±0.16W），各自倾斜 2.5–5°；如果左右位移不到一个头高（`max(0.10H, 0.14×贴纸高)`），B 位再加一点向上的跳（A/B 场景最多 0.075H）。
- **只有一个主变化**【硬锁定】：摇镜落位后才开始跳动 / A/B，跳动不和摇镜同帧。
- **摇镜**：每步 1T 硬切；纵向每步 0.18H，横向 0.24W，不缓动。

## 画面规则
- **层级**（P0-3/4）：底色整页纸 → 1–2 张大撕纸色块 → 建筑/风景照片（v6：近满版、不规则遮罩、12px 白纸边 + 轻投影）→ 信息卡（信笺/流程卡/日期卡）→ 文字 → 涂鸦 → 道具 → 接触阴影 → **人物**。
- **人物站在场景里（改进 1）**：有风景时，脚底对齐照片里的地面线（`landscape_ground`，街道/沙滩/草地），脚下有一块柔和的接触阴影（跳起来时阴影留在地面）；没有风景时脚在底边，可以被底边裁掉。人物高 0.50H（风景场景 ×0.92），放不下两个位置时按 1 → 0.76 逐级缩小。
- **留白（改进 4）**：每场景 = 大色块 + 1 张照片 + 一对人 + 1 句话 + 最多 1 个道具（+ 最多 1 个涂鸦，只在 S2/S4/S6/S8/S9 里抽）。不再加报纸条、小撕纸、地面条。
- **统一色彩（改进 3）**：每场景 1 个主色（底纸）+ 1 个强调色（大撕纸）；第三层只能是主色的浅色。所有风景照片用同一个胶片暖调（`sepia .22 saturate .72 contrast .94`），再用场景主色 soft-light 30% 拉向色板。
- **纸感（改进 6）**：每层色块都叠皱纸纹理（multiply 26–30%）和细颗粒；撕边下面露出白色纸纤维（白色底边 + 毛刺纤维线）。
- **字体：只用手写体（改进 2）**：
  - 英文：细笔画流动手写——Reenie Beanie、Nothing You Could Do、Homemade Apple、Caveat、Dancing Script（随机抽，按字体系数调字号：大字、细笔画）；最小 118px×字体系数。
  - 勒索信标题（S2）：保留剪纸底块，字形改成手写（Caveat / Dancing Script / Kalam）。
  - 中文：马善政 Ma Shan Zheng（OFL，Google Fonts）——所有中文（S3 信笺、S9 流程+标题、S10 日期/地点/厅名）默认都用它；最小 46px。v8 钢笔墨迹渲染（render.js `inkText`/`INK`）：近黑 #1A1A22、不透明、每字笔画膨胀 2.8–5% 字号、轻微起笔重收笔轻（末端 84–93%）、弱墨流噪声、轻微晕染、multiply 透出纸纹、每字大小 ±5–8%/旋转 ±3°/基线抖动，按 seed 确定。可用 manifest `style.zhBody/zhTitle/penInk` 覆盖（候选对比见 test_v8/font_compare.jpg）。
  - 不再用 Bebas Neue / Abril Fatface / Alfa Slab One / Permanent Marker / Caveat Brush / 站酷快乐体。
  - 文字颜色从 [墨色, 纸白, 强调色, 强调色加深] 里按实际背景中位亮度挑对比度最高的，要求 ≥3:1。
- **S1 开场（改进 7）**：真实复古电视照片（Philco Predicta 抠图），玻璃屏用 `tv_screen.py` 精确检测（圆角矩形 + 四边形），屏里播下一场景 S2，玻璃加一层斜向反光；推镜以玻璃中心为锚点，三步缩放 `full^(n/3)`，第二步时玻璃中心已移到画面中心，第三步（65 帧）正好接 S2 全屏。
- **S10 结尾（改进 7）**：奶油色信息卡（日期、地点、厅名）+ 一排 5 个撕纸色卡（同一基线，下面手写色号）+ 结束语 + 两个撕纸名牌（粉色胶带），名牌放在卡片下方、人物头顶上方，互不重叠。
- **贴纸白边**：0.97% 画面宽；只加 1.5px 暗边，不加大投影。

## 随机系统（详见 references/randomness.md）
seed 决定：色块撕法（对角/侧边/大圆弧）和位置、撕边轮廓、照片微旋转、英文字体、文字位置和颜色、可选道具和涂鸦的有无与位置、勒索信底块形状和颜色、A/B 位置的左右方向和倾斜。**永不随机**：时间轴、boil/A-B 帧、层级、两个位置的规则、人物脚线、最小字号、建筑居中。所有随机结果都要过 P0 审计。

## 签名速查（完整版见 references/signature.md）
3 态 boil｜A/B 只在 S5–S7｜步进摇镜不缓动｜只有一次硬切｜首尾砖红｜一场景一主色一照片一句话｜英文情话用古典文学｜勒索信标题只出现一次｜真实复古道具｜涂鸦极少｜冷暖交替｜结尾色卡｜TV 开场。
最容易破坏原作感的做法：平滑缓动或叠化、大投影或发光、满屏小色块、插画道具、粗体展示字、中文写情话、直边矩形、人物被遮挡、人物越出左右上边、超过两个位置。

## 缺素材时问什么（按优先级，一次最多问 3 件）
1. **S5–S7 的 A/B 照**：每场景 2 张，同一场景、同一组拍摄，两人位置明显不同（换站位、一前一后、拉远牵手）。缺了降级成单张跳动并说明。
2. 两人称呼和拼音、婚礼日期、地点、厅名、流程时间。
3. BGM（没有就问能不能用免版权曲，140–150 BPM 最贴原网格）。
